# 数智化知识中台 - 面试反馈

## 2026-04-09 CKEditor 5 专项面试

- 表现：⚠️ 有缺口
- 考察要点：CKEditor 5 插件机制、关联知识插入插件流程、inline widget 实现、预览渲染策略、文档分片加载、源码改造踩坑
- 回答概要：
  - 插件基本结构：混淆了 CKEditor 4 的 `extraPlugins` 概念，生命周期方法说不全
  - 关联知识插入流程：经引导后能说清楚插件-业务层事件解耦架构，但一开始说不出来
  - 预览渲染：清楚区分是链接/下载而非内嵌内容
  - 分片加载：前后端分批拉取方案说得清楚
  - 源码改造踩坑：梳理后能完整描述事件冒泡冲突的排查和解决过程
- 薄弱点：CKEditor 5 底层 API 不熟悉；自己项目细节需要提前梳理话术
- 改进方向：
  1. 过一遍 CKEditor 5 Plugin 基础 API：Plugin 类、init/afterInit/destroy 生命周期、schema.register、conversion.for
  2. 给每个定制插件写 30 秒话术模板：做了什么 → 怎么做的 → 遇到什么问题 → 怎么解决的
