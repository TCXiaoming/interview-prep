# 重排与重绘

## 核心概念

**重排（Reflow）**：元素的尺寸、位置、布局发生变化，浏览器需要重新计算几何信息，影响范围可能波及整个页面。

**重绘（Repaint）**：元素外观变化（颜色、背景、阴影），但不影响布局，只需重新绘制该元素。

**关系**：重排必然触发重绘，重绘不一定触发重排。

### 触发重排的操作
- 修改尺寸：width/height/padding/margin/border
- 修改字体大小（影响元素尺寸）
- 添加/删除 DOM 节点
- 读取布局属性：`offsetWidth`、`offsetHeight`、`getBoundingClientRect()`、`scrollTop` 等（强制刷新队列）

### 只触发重绘的操作
- color、background-color、box-shadow、border-radius（不影响布局）

## 减少重排的具体手段

**1. DocumentFragment（批量插入）**
```js
const fragment = document.createDocumentFragment()
items.forEach(item => {
  const li = document.createElement('li')
  li.textContent = item
  fragment.appendChild(li) // 操作内存中的 fragment
})
ul.appendChild(fragment) // 一次性插入，只触发一次重排
```

**2. 先隐藏再操作**
```js
el.style.display = 'none'  // 第1次重排
// 批量操作 el...
el.style.display = 'block' // 第2次重排，共2次
```

**3. 批量修改样式**
```js
// 差：每行都可能触发重排
el.style.width = '100px'
el.style.height = '200px'
el.style.margin = '10px'

// 好：一次性修改
el.className = 'new-class'
// 或
el.style.cssText = 'width:100px; height:200px; margin:10px'
```

**4. 读写分离（避免强制同步布局）**
```js
// 差：读写交替，每次读都强制刷新队列
const h1 = el1.offsetHeight // 读
el1.style.height = h1 + 'px' // 写
const h2 = el2.offsetHeight // 读（强制重排）
el2.style.height = h2 + 'px' // 写

// 好：先读后写
const h1 = el1.offsetHeight
const h2 = el2.offsetHeight
el1.style.height = h1 + 'px'
el2.style.height = h2 + 'px'
```

## 常见追问

- transform 动画为什么不触发重排？
- 什么是强制同步布局？
- 虚拟 DOM 是怎么减少重排的？

## 回答要点

**transform/opacity 不触发重排重绘**：这两个属性的变化由 GPU 合成层处理，完全跳过 Layout 和 Paint 阶段，是性能最好的动画方式。

**虚拟 DOM 减少重排**：批量计算 diff，一次性将变更 patch 到真实 DOM，本质是"批量操作"思路。
