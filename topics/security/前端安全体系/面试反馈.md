# 面试反馈

## 2026-04-30 综合面试记录

- 表现：⚠️ 有缺口
- 考察要点：XSS 三种类型、CSP 机制和配置
- 回答概要：知道 XSS 是注入攻击、需要转义防范，但说不清反射型/存储型/DOM 型的区别和 CSP 的 `script-src` 行为
- 薄弱点：说不清 XSS 三种类型的具体攻击链路；不清楚 CSP `'self'` 策略对内联脚本的限制
- 改进方向：用具体例子理解每种 XSS 的触发链；记住 CSP 配置中 `'self'` 禁止内联，需要 `'unsafe-inline'` 或 nonce 放行

## 2026-05-05 综合面试记录

- 表现：⚠️ 有缺口
- 考察要点：XSS 三种类型、CSP 防御机制、DOM 型 XSS 与其他两种的本质区别
- 回答概要：能说出存储型/反射型/DOM 型三种类型；知道 CSP 限制域名和禁用内联；但对 DOM 型 XSS 的本质（不经过服务器、纯客户端注入）理解不够精确
- 薄弱点：DOM 型 XSS 的典型场景不清楚（如 URL hash 被 innerHTML）
- 改进方向：记住 DOM 型核心特征——服务器返回的 HTML 是干净的，恶意代码完全在客户端通过 JS 操作 DOM 注入；CSP 对 DOM 型 XSS 无效
