# CKEditor 5 插件机制 - 常见问题

## Q1：CKEditor 5 的插件是怎么注册的？

CKEditor 5 的插件是继承 `Plugin` 类的 class。注册方式有两种：
1. 在编辑器类的 `builtinPlugins` 数组中添加（最常用）
2. 通过 `config.extraPlugins` 配置追加

注意：CKEditor 4 的 `CKEDITOR.plugins.add()` 和 `extraPlugins` 字符串配置是另一套 API，不要混淆。

## Q2：插件的生命周期方法有哪些？分别什么时候调用？

- `init()`：编辑器初始化时调用，用于注册命令、schema、绑定事件、注册 UI 组件
- `afterInit()`：所有插件的 `init()` 执行完后调用，适合做依赖其他插件的初始化
- `destroy()`：编辑器销毁时调用，用于清理事件监听、释放资源

## Q3：schema.register() 里的 isInline、isObject、isBlock 分别是什么意思？

- `isInline`：行内元素，类似 `<span>`，可以出现在文本流中
- `isBlock`：块级元素，类似 `<div>`，独占一行
- `isObject`：不可分割的整体，类似图片。即使它本身是 inline 的，也不会被光标拆开

可以组合使用，比如 `isInline: true, isObject: true` 就是一个行内的不可分割对象（类似图片放在文本中）。

## Q4：Downcast 和 Upcast 分别在什么时候触发？

- **Downcast**：model 数据变化时触发，将 model 转换成 view（用户看到的内容）。每次编辑器内容变化都会触发增量 downcast
- **Upcast**：加载 HTML 内容时触发，将 view（HTML）转成 model。发生在 `editor.setData()` 或粘贴内容时

## Q5：Widget 和普通 container element 有什么区别？

Widget 是通过 `toWidget()` 包装过的 view element，额外获得了交互行为：
- 点击选中整个元素，不能编辑内部
- 可整体删除、移动
- 有选中态高亮
- 方向键跳过整个 widget

普通 container element 就是普通的 view 元素，没有这些特殊交互。

## Q6：如何实现自定义工具栏按钮？

通过 `editor.ui.componentFactory.add()` 注册按钮，返回一个 `ButtonView` 实例。按钮点击时触发自定义 Command 或业务逻辑。

```js
editor.ui.componentFactory.add('myButton', locale => {
  const button = new ButtonView(locale);
  button.set({ label: '插入知识', withText: true });
  button.on('execute', () => {
    editor.execute('myCommand');
  });
  return button;
});
```

## Q7：多个插件监听同一事件时，执行顺序怎么控制？

CKEditor 5 没有保证插件间的事件执行顺序。如果需要确保优先级，可以用事件的 `priority` 参数：

```js
dispatcher.on('event', handler, { priority: 'high' });
```

或者不依赖执行顺序，在上层统一代理处理。

## Q8：CKEditor 5 的 View 层和 Vue/React 的虚拟 DOM 有什么区别？

CKEditor 5 的 View 层是它自己独立维护的视图抽象树，有自己的 `ViewDocument`、`ViewElement`、`ViewText` 等节点类型。它不是浏览器 DOM，也不是 Vue/React 的虚拟 DOM。

三层关系：
- Model 树（CKEditor 内部数据）→ Downcast → View 树 → Rendering → 真实 DOM
- 插件操作的是 View 树，不直接操作 DOM
- Vue/React 有自己的虚拟 DOM diff 机制，和 CKEditor 的 View 层是完全独立的两套系统

## Q9：怎么在 CKEditor 插件里用 Vue/React 做 UI？

核心思路：在插件中创建 DOM 容器，挂载 Vue/React 组件，销毁时清理。

以 Vue 为例：
1. 插件注册工具栏按钮
2. 按钮点击时创建 DOM 容器，用 `createApp()` 挂载 Vue 组件
3. Vue 组件选中数据后，通过回调函数将数据传回插件
4. 插件通过 `editor.model.change()` 将数据插入 model
5. 插件 `destroy()` 时调用 `app.unmount()` 清理

关键注意事项：
- 生命周期管理：destroy 时必须卸载框架实例，否则内存泄漏
- 事件通信：组件和插件之间通过回调通信，不要让组件直接引用 editor 实例
- 选区保持：框架组件获得焦点时 CKEditor 选区可能丢失，需要保存/恢复选区
- 弹窗定位：以编辑器光标 DOM 位置为锚点，而不是视口

## Q10：怎么在编辑器内容区域里嵌入 Vue/React 组件？

Downcast 时创建自定义 View 元素，通过 `render` 方法将框架组件挂载到 DOM 容器上：

1. Downcast 中用 `writer.createUIElement()` 创建自定义 View 元素
2. 在 `render` 回调中创建真实 DOM 容器
3. 将 Vue/React 组件挂载到这个 DOM 容器上
4. CKEditor 的 rendering pipeline 会将 View 元素同步到真实 DOM

注意：这种方式需要处理好 CKEditor 的 diff 机制和框架的 diff 机制的冲突。
