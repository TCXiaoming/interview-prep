# 面试反馈

## 2026-04-02 面试记录

- 表现：⚠️ 有缺口
- 考察要点：闭包本身 vs 闭包导致内存泄漏的区别
- 回答概要：知道闭包可能导致内存泄漏，知道置 null 可以解决，但说不清"什么情况才算泄漏"
- 薄弱点：不能清晰区分正常闭包和泄漏闭包的判断标准
- 改进方向：记住判断标准：不再需要的变量，还有没有引用链阻止 GC 回收；结合简历内存泄漏排查经历来说更有说服力

## 2026-02-22 面试记录

- 表现：⚠️ 有缺口
- 考察要点：闭包的定义、闭包与普通作用域链查找的区别
- 回答概要：回答"闭包就是函数能访问外部变量的一个特性"，追问闭包和普通作用域访问的区别时未能进一步展开
- 薄弱点：无法区分闭包和普通作用域链查找；不清楚闭包的关键在于函数在词法作用域之外执行时仍持有外部变量引用；底层机制（`[[Environment]]`、GC）未涉及
- 改进方向：重点理解"函数在定义作用域之外被调用"这个关键条件，手写 createCounter 类的例子体会变量存活机制，准备一个 30 秒的闭包定义 + 例子的口述版本

## 2026-04-30 综合面试记录

- 表现：⚠️ 有缺口
- 考察要点：闭包内存机制（[[Scopes]] / 作用域链）、for 循环 + var 经典场景
- 回答概要：知道闭包的概念——函数访问外部变量并保持引用——但说不清闭包在 V8 中的具体内存表示
- 薄弱点：不清楚 `[[Scopes]]` 链表结构；for 循环 + var 的闭包问题不知道具体原因
- 改进方向：在 DevTools 中实际打断点查看 `[[Scopes]]` 链；理解 var 没有块级作用域的本质
