## 2026-04-02 面试记录

- 表现：⚠️ 有缺口
- 考察要点：== 和 === 的区别，== 的隐式转换规则
- 回答概要：把 == 和 === 说反了（说 === 做类型转换），转换规则不清楚
- 薄弱点：== 做隐式转换，=== 不转换；null==undefined、布尔先转数字等规则不熟
- 改进方向：记住核心转换规则，实际开发用 === 即可，面试能说出 null==undefined 这个特例

## 2026-05-05 综合面试记录

- 表现：✅ 扎实
- 考察要点：`[] == ![]` 的完整转换链路
- 回答概要：能说出完整链路——![] 优先执行得 false → 布尔值转数字得 0 → 对象转原始值（valueOf→toString）得 "" → 字符串转数字得 0 → 0==0 为 true
- 薄弱点：无
- 改进方向：从之前说反 == 和 === 到完全掌握，进步明显
