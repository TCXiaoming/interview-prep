## 2026-04-02 面试记录

- 表现：⚠️ 有缺口
- 考察要点：普通函数 this 是定义时还是调用时确定
- 回答概要：一开始说普通函数定义时确定（说反了），追问后纠正，能举出 call/apply/bind 和对象调用的例子
- 薄弱点：this 绑定规则没有系统梳理，容易混淆
- 改进方向：系统掌握四种绑定规则及优先级

## 2026-05-05 面试记录

- 表现：⚠️ 有缺口
- 考察要点：独立调用 this 指向、箭头函数 this 定义时决定
- 回答概要：独立函数调用场景（fn()）判断为指向 obj，方向错误；箭头函数说成"调用时决定"（实际是定义时捕获外层 this）
- 薄弱点：独立调用规则不熟（严格模式 undefined / 非严格 window）；箭头函数 this 始终是定义时的外层作用域
- 改进方向：记住三条规则——(1) .fn() 看 . 前面是谁 (2) 独立调用 fn() 严格模式 undefined (3) 箭头函数 this 看定义时最外层普通函数的 this
