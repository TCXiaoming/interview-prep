## 2026-04-03 综合面试记录

- 表现：⚠️ 有缺口
- 考察要点：原型链基本概念、__proto__/prototype/constructor 三角关系、class extends 双重原型链
- 回答概要：能说出属性查找沿原型链向上查找的过程，但 __proto__ 和 prototype 关系一开始说混了（把 Foo.__proto__ 说成指向 Foo.prototype）；class extends 底层完全不清楚
- 薄弱点：Foo.__proto__ 实际指向 Function.prototype（函数对象），不是 Foo.prototype；class extends 的双重原型链（静态继承 + 实例继承）
- 改进方向：反复画 new、Object.create、class extends 三种方式的完整原型链图；记住 class extends 做了 Child.__proto__ = Parent 和 Child.prototype.__proto__ = Parent.prototype 两步
