# useMemo 与 useCallback

## 核心概念

两者都是缓存 Hook，区别在于缓存的内容：

| | useMemo | useCallback |
|---|---|---|
| 缓存内容 | 计算结果（值） | 函数引用 |
| 类比 | Vue computed | - |
| 语法 | `useMemo(() => compute(), deps)` | `useCallback(() => fn(), deps)` |

`useCallback(fn, deps)` 等价于 `useMemo(() => fn, deps)`。

## 常见追问

- useCallback 单独用有意义吗？
- useMemo 什么时候值得用？
- 过度使用 useMemo/useCallback 有什么问题？

## 回答要点

**useCallback 要配合 React.memo 才有意义**：

```jsx
// 父组件每次渲染都创建新函数引用
const handleClick = useCallback(() => {
  doSomething()
}, []) // 依赖不变，返回同一引用

// 子组件用 React.memo 包裹，props 没变就不重渲染
const Child = React.memo(({ onClick }) => <button onClick={onClick} />)
```

不用 `useCallback`：父组件重渲染 → 新函数引用 → `React.memo` 认为 props 变了 → 子组件重渲染（memo 失效）。

**useMemo 适用场景**：计算开销大（大数组过滤/排序），或需要稳定引用传给子组件的对象/数组。

**过度使用的问题**：每次渲染都要执行依赖比较，缓存本身有开销。简单计算直接算比缓存更快，不要滥用。
