# CSS position 定位

## 核心概念

| 值 | 行为 | 脱离文档流 |
|---|---|---|
| `static` | 默认，按正常流排列 | 否 |
| `relative` | 相对自身原位置偏移，原位置仍占空间 | 否 |
| `absolute` | 相对最近非 static 祖先定位 | 是 |
| `fixed` | 相对视口定位，滚动不移动 | 是 |
| `sticky` | 滚动前是 relative，滚动超过阈值变 fixed | 否 |

## absolute 的定位参照

往上找第一个 `position` 值**不是 `static`** 的祖先元素（relative、absolute、fixed、sticky 都算）。找不到则相对 `<html>` 根元素。

```css
/* 常见用法：父元素 relative，子元素 absolute */
.parent { position: relative; }
.child  { position: absolute; top: 0; right: 0; }
```

## sticky 的行为

```css
.header {
  position: sticky;
  top: 0; /* 滚动到距视口顶部 0px 时"粘住" */
}
```

- 滚动到阈值前：表现像 `relative`，在正常文档流中
- 滚动超过阈值：表现像 `fixed`，固定在视口位置
- 离开父容器范围：随父容器滚走，不再粘住

**常见用途**：表格固定表头、页面固定导航栏。

## 常见追问

- `relative` 和 `absolute` 都可以用 top/left 偏移，有什么区别？
- `fixed` 在 `transform` 父元素下会失效吗？
- `z-index` 在什么情况下生效？

## 回答要点

**relative vs absolute 偏移**：
- `relative`：相对自身原位置偏移，原位置仍占据空间
- `absolute`：脱离文档流，原位置不占空间，相对定位祖先偏移

**fixed 在 transform 下失效**：父元素有 `transform`、`filter`、`perspective` 时，`fixed` 的参照变成该父元素而不是视口，这是常见的坑。

**z-index 生效条件**：元素必须是定位元素（position 不为 static）或 flex/grid 子元素，z-index 才生效。
