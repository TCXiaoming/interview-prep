## 2026-05-06 面试记录

- 表现：⚠️ 有缺口
- 考察要点：五种 position 值定位参照、sticky 生效条件、fixed 的特殊情况
- 回答概要：能说清 relative/absolute/fixed/sticky/static 的定位参照；absolute 和 fixed 脱离文档流也说对了；但 sticky 生效条件不清楚（需要阈值、容器不能 overflow:hidden）、fixed 的 transform 祖先坑点不熟
- 薄弱点：sticky 需要至少设一个阈值（top/bottom/left/right）和容器不能 overflow: hidden；fixed 默认相对视口，但祖先有 transform/perspective/filter 时会改为相对该祖先
- 改进方向：记住 sticky 的三条件——设阈值 + 容器不能 overflow hidden + 容器有高度；记住 fixed 的 transform 祖先坑点
