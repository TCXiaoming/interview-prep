# 层叠上下文

## 核心概念

层叠上下文（Stacking Context）是 HTML 元素在三维空间中的**层叠顺序**概念——沿着 Z 轴（垂直于屏幕方向）的排列规则。

### 层叠上下文 vs z-index

- `z-index` 只在**同一个层叠上下文内**比较大小
- 不同层叠上下文里的元素，`z-index` 没有可比性——子元素的 z-index 再大，也不会超过父上下文之外的元素

```html
<!-- 例：子元素 z-index: 999 不会高于父上下文外的元素 -->
<div style="z-index: 1; position: relative;">
  <div style="z-index: 999; position: relative;"><!-- 实际层叠等级 = 1 --></div>
</div>
<div style="z-index: 2; position: relative;"><!-- 这个在顶层 --></div>
```

### 创建层叠上下文的条件

| 条件 | 示例 |
|------|------|
| `position` + `z-index` | `position: relative/absolute/fixed` + `z-index` 不为 auto |
| `opacity < 1` | `opacity: 0.9` |
| `transform` 非 none | `transform: scale(1)` |
| `filter` 非 none | `filter: blur(2px)` |
| `clip-path` 非 none | `clip-path: polygon(...)` |
| `will-change` | `will-change: transform` |
| `contain` | `contain: layout/paint` |
| flex/grid 子项 + `z-index` | `display: flex` 的子项设了 `z-index` |

### 层叠等级（Stacking Level）

同一层叠上下文内，从后到前（从屏幕里到外）的顺序：

1. 背景和边框（创建上下文的元素本身）
2. 负 z-index（`z-index < 0`）
3. 块级元素（block / float）
4. 行内元素（inline / inline-block）
5. z-index: auto（不创建上下文的定位元素）
6. 正 z-index（`z-index >= 1`）

## 常见追问

1. 什么情况下会创建新的层叠上下文？
2. z-index: 999 就一定在上层吗？
3. 层叠上下文和 BFC（块级格式化上下文）有什么区别？
4. opacity + z-index 一起用会有什么影响？
5. 如何调试复杂的层叠问题？

## 回答要点

### z-index 失效的场景

- 元素没有设置 `position`（static 元素 z-index 无效）
- 元素处于一个更低的层叠上下文中，父上下文的 z-index 比另一个上下文低
- `position: fixed/sticky` 默认在根上下文，不创建新上下文

### 调试技巧

Chrome DevTools 的 Elements → Computed → "Stacking context" 可以直观看到元素的层叠上下文树，比猜 z-index 值高效得多。

### 面试常见场景题

```
A (z-index: 10) 和 B (z-index: 1)
但 A 在一个 z-index: 0 的父容器中
→ A 的实际层叠等级受限于父容器，不一定高于 B
```
