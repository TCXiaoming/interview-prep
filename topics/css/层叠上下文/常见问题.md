# 层叠上下文 常见问题

### Q: 为什么我设置了 z-index: 9999，元素还是被挡住了？

**回答要点：**
z-index 只在同一个层叠上下文内生效。如果该元素在一个 z-index 较低的父上下文中，子元素 z-index 再大也不会超出父上下文。检查父元素是否有 `opacity < 1`、`transform: scale(1)` 等隐藏创建上下文的条件。

### Q: opacity: 0.5 会影响 z-index 吗？

**回答要点：**
会。`opacity < 1` 会创建新的层叠上下文，所以子元素的 z-index 会被限制在这个新上下文中。在 CSS 动画中常见这个问题——动画改变了 opacity 导致上下文变化。

### Q: 层叠上下文和 BFC 有什么区别？

**回答要点：**
- 层叠上下文控制 Z 轴排列（前后关系）
- BFC（Block Formatting Context）控制文档流排列（上下关系、外边距合并）
- 有些属性同时触发两者，比如 `overflow: hidden`

### Q: position: fixed 的元素层叠规则是什么？

**回答要点：**
`position: fixed` 元素默认在根层叠上下文中（不随父元素滚动），但如果父元素有 `transform` 属性，fixed 元素的包含块会变为该父元素，同时层叠上下文也会受限于该父元素。
