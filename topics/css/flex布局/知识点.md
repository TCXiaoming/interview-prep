# flex 布局

## 核心概念

`flex: 1` 是三个属性的简写：

```css
flex-grow: 1;    /* 有剩余空间时，按比例放大 */
flex-shrink: 1;  /* 空间不足时，按比例缩小 */
flex-basis: 0%;  /* 初始尺寸为 0，从 0 开始分配空间 */
```

### flex:1 vs flex:auto

```css
flex: 1;    /* flex-basis: 0%  — 忽略内容尺寸，纯按比例等分 */
flex: auto; /* flex-basis: auto — 先按内容占位，剩余空间再按比例分 */
```

场景区别：
- 等分容器 → 用 `flex: 1`
- 按内容比例分配 → 用 `flex: auto`

## 常见追问

- `flex-grow: 2` 和 `flex-grow: 1` 的比例是怎么算的？
- `flex-shrink` 缩小时是按什么比例？
- `align-items` 和 `align-content` 有什么区别？

## 回答要点

**flex-grow 计算**：剩余空间按 grow 值的比例分配。

```
父容器 500px，子元素 A(flex-grow:1) B(flex-grow:2)，初始都是 0
剩余空间 500px，A 分 500 * 1/3 ≈ 167px，B 分 500 * 2/3 ≈ 333px
```

**flex-shrink 计算**：超出空间按 shrink 值 × flex-basis 的加权比例缩小，不是简单按比例。

**align-items vs align-content**：
- `align-items`：控制单行内每个子元素的交叉轴对齐
- `align-content`：控制多行之间的对齐（只有换行时才生效）

**常用 flex 速记**：
```css
/* 水平垂直居中 */
display: flex;
justify-content: center;
align-items: center;

/* 两端对齐 */
justify-content: space-between;

/* 子元素等分 */
.child { flex: 1; }
```
