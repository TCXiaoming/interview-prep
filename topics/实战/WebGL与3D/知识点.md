# WebGL 与 3D

## WebGL 基础概念

### 什么是 WebGL

WebGL（Web Graphics Library）是基于 OpenGL ES 2.0 的 JavaScript API，允许在浏览器中直接使用 GPU 渲染 2D/3D 图形，不需要插件。

### 渲染管线

```
顶点数据 → 顶点着色器 → 图元装配 → 光栅化 → 片元着色器 → 帧缓冲 → 屏幕
```

1. **顶点着色器（Vertex Shader）** — 处理每个顶点的位置变换
2. **图元装配** — 将顶点连接成图元（点、线、三角形）
3. **光栅化** — 将图元转化为片元（像素候选）
4. **片元着色器（Fragment Shader）** — 计算每个片元的颜色

### Shader 基础

```glsl
// 顶点着色器
attribute vec4 a_position;  // 顶点坐标
uniform mat4 u_matrix;      // 变换矩阵
void main() {
  gl_Position = u_matrix * a_position;
}

// 片元着色器
precision mediump float;
uniform vec4 u_color;
void main() {
  gl_FragColor = u_color;  // 输出颜色
}
```

## MVP 矩阵（核心概念）

### 模型矩阵（Model Matrix）

将顶点从**模型坐标系**（模型自身的坐标系）变换到**世界坐标系**。

包含：平移、旋转、缩放变换。

```js
const modelMatrix = mat4.create();
mat4.translate(modelMatrix, modelMatrix, [x, y, z]);
mat4.rotateX(modelMatrix, modelMatrix, angle);
mat4.scale(modelMatrix, modelMatrix, [sx, sy, sz]);
```

### 视图矩阵（View Matrix）

将顶点从**世界坐标系**变换到**相机坐标系**（以相机为原点的坐标系）。

等价于将相机变换到原点、朝向 -Z 方向的逆变换。

```js
const viewMatrix = mat4.create();
mat4.lookAt(viewMatrix, eyePosition, targetPosition, upVector);
```

### 投影矩阵（Projection Matrix）

将顶点从**相机坐标系**变换到**裁剪坐标系**（标准化设备坐标 NDC，范围 [-1, 1]）。

**透视投影（Perspective）：** 近大远小，模拟人眼。
```js
const projMatrix = mat4.create();
mat4.perspective(projMatrix, fov, aspect, near, far);
```

**正交投影（Orthographic）：** 等比例，无近大远小，适合 2D 和工程制图。

### 完整变换

```
gl_Position = Projection * View * Model * vertex_position;
```

## 坐标系

### 本地坐标系 vs 世界坐标系

| 坐标系 | 定义 | 转换方式 |
|---|---|---|
| 本地坐标系 | 以模型自身中心为原点 | 乘以模型矩阵 |
| 世界坐标系 | 以场景原点为参考 | 本地 × 模型矩阵 |
| 相机坐标系 | 以相机为原点 | 世界 × 视图矩阵 |
| 裁剪坐标系 | NDC [-1, 1] | 相机 × 投影矩阵 |

**互相转换：**
- 本地 → 世界：乘以 Model 矩阵
- 世界 → 本地：乘以 Model 矩阵的逆矩阵

## Shader 实战

### 淡入淡出效果

```glsl
// 片元着色器
precision mediump float;
uniform sampler2D u_texture;
uniform float u_time;  // 0 → 1 表示过渡进度
varying vec2 v_texCoord;

void main() {
  vec4 color = texture2D(u_texture, v_texCoord);
  gl_FragColor = vec4(color.rgb, color.a * u_time);  // alpha 渐变
}
```

### 灰度图（黑白滤镜）

```glsl
precision mediump float;
uniform sampler2D u_texture;
varying vec2 v_texCoord;

void main() {
  vec4 color = texture2D(u_texture, v_texCoord);
  // 人眼对不同颜色敏感度不同，加权平均
  float gray = dot(color.rgb, vec3(0.299, 0.587, 0.114));
  gl_FragColor = vec4(vec3(gray), color.a);
}
```

### 画圆

```glsl
precision mediump float;
uniform vec2 u_resolution;

void main() {
  vec2 center = u_resolution * 0.5;
  float radius = min(u_resolution.x, u_resolution.y) * 0.3;
  float dist = distance(gl_FragCoord.xy, center);
  // smoothstep 做抗锯齿边缘
  float alpha = 1.0 - smoothstep(radius - 1.0, radius + 1.0, dist);
  gl_FragColor = vec4(1.0, 0.0, 0.0, alpha);
}
```

## 三维概念

### 欧拉角 vs 四元数

| 维度 | 欧拉角 | 四元数 |
|---|---|---|
| 表示 | 三个角度 (pitch, yaw, roll) | 四个数 (x, y, z, w) |
| 万向锁 | 有（当旋转 90° 时丢失一个自由度） | 无 |
| 插值 | 不平滑 | 球面线性插值（SLERP），平滑 |
| 直观性 | 人类容易理解 | 不直观 |
| 实际使用 | 用户输入（拖拽旋转） | 内部计算和动画 |

**万向锁：** 当绕 Y 轴旋转 90° 后，X 轴和 Z 轴重合，丢失一个旋转自由度。四元数不存在这个问题。

## Babylon.js vs Three.js

| 维度 | Three.js | Babylon.js |
|---|---|---|
| 定位 | 渲染引擎，更底层 | 游戏引擎，更完整 |
| 学习曲线 | 较陡 | 较平缓（文档好） |
| 性能 | 需要手动优化 | 内置优化多 |
| 适用场景 | 自定义渲染、视觉效果 | 游戏、交互式应用 |

## WebGL vs WebGPU

| 维度 | WebGL | WebGPU |
|---|---|---|
| 基础 | OpenGL ES 2.0 | Vulkan/Metal/DX12 |
| 纹理范围 | 归一化 [0,1] | 取决于格式 |
| 计算着色器 | 不支持 | 支持（Compute Shader） |
| 性能 | 单线程命令提交 | 多线程命令提交 |
| 状态 | 全局状态机 | 显式管线对象 |

## 拖拽选择 WebGL 图形

**实现思路：**
1. 将鼠标坐标转换为 NDC（归一化设备坐标）
2. 从相机位置发射一条射线（Ray）
3. 将射线与场景中的物体做碰撞检测（射线-三角形相交测试）
4. 命中则选中，记录偏移量用于拖拽

```js
// 鼠标坐标 → NDC
const ndcX = (mouseX / canvas.width) * 2 - 1;
const ndcY = -(mouseY / canvas.height) * 2 + 1;

// 从 NDC → 世界空间射线
const invMatrix = mat4.invert(mat4.create(), projMatrix * viewMatrix);
const nearPoint = mat4.transformPoint(invMatrix, [ndcX, ndcY, -1]);
const farPoint = mat4.transformPoint(invMatrix, [ndcX, ndcY, 1]);
const rayDir = normalize(farPoint - nearPoint);
```

## 常见追问

### Q: 你用过 WebGL 做什么？

**如果没有实际 WebGL 经验，可以回答：**
- 了解 WebGL 渲染管线和 Shader 基本原理
- 在学习过程中实现过基础图形渲染、滤镜效果
- 理解 MVP 矩阵变换和坐标系转换
- 大疆的产品（如 DJI Fly App 的 3D 地图、飞行模拟）可能会用到 WebGL/Three.js

### Q: 什么时候用 Canvas 2D，什么时候用 WebGL？

**回答要点：**
- **Canvas 2D** — 简单的 2D 图形、图表、图片处理、动画
- **WebGL** — 3D 渲染、大量图形（性能更好）、GPU 加速的图像处理、游戏
- **判断标准**：如果需要逐像素操作或 3D 效果，用 WebGL；简单 2D 场景 Canvas 2D 更简单
