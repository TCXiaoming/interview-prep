# CSS 与布局（实战向）

## 盒模型

### 标准盒模型 vs IE 盒模型

```
标准盒模型（content-box）：
  width = content
  总宽度 = width + padding*2 + border*2

IE 盒模型（border-box）：
  width = content + padding*2 + border*2
  总宽度 = width
```

`box-sizing: border-box` 更符合直觉，实际项目中通常全局设置：
```css
*, *::before, *::after { box-sizing: border-box; }
```

## BFC（Block Formatting Context）

**触发条件：**
- `overflow` 不为 `visible`
- `display: flow-root`（专门创建 BFC）
- `float` 不为 `none`
- `position: absolute / fixed`
- `display: inline-block / table-cell / flex / grid`

**解决问题：**
1. **Margin 塌陷** — 父子元素的 margin 合并，创建 BFC 隔离
2. **高度塌陷** — 子元素浮动后父元素高度为 0，BFC 包含浮动元素
3. **两栏布局** — BFC 不与浮动元素重叠

## 三栏布局方案

```css
/* 方案 1：Flexbox（推荐） */
.container { display: flex; }
.left { width: 200px; }
.center { flex: 1; }
.right { width: 200px; }

/* 方案 2：Grid */
.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
}

/* 方案 3：圣杯布局（float + 负 margin + padding） */
.container { padding: 0 200px; }
.left { float: left; width: 200px; margin-left: -100%; position: relative; left: -200px; }
.center { float: left; width: 100%; }
.right { float: left; width: 200px; margin-left: -200px; }

/* 方案 4：双飞翼布局 */
.center-wrapper { float: left; width: 100%; }
.center { margin: 0 200px; }
.left { float: left; width: 200px; margin-left: -100%; }
.right { float: left; width: 200px; margin-left: -200px; }
```

## 垂直居中方案

```css
/* 1. Flex（最推荐） */
.parent { display: flex; align-items: center; justify-content: center; }

/* 2. Grid */
.parent { display: grid; place-items: center; }

/* 3. 绝对定位 + transform */
.child {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}

/* 4. 绝对定位 + margin: auto（子元素宽高已知） */
.child {
  position: absolute;
  top: 0; right: 0; bottom: 0; left: 0;
  margin: auto;
  width: 100px; height: 100px;
}

/* 5. Table-cell */
.parent {
  display: table-cell;
  vertical-align: middle;
  text-align: center;
}
```

## 1px 问题（Retina 屏）

```css
/* 方案 1：伪元素 + transform */
.border-1px {
  position: relative;
}
.border-1px::after {
  content: '';
  position: absolute;
  left: 0; bottom: 0;
  width: 100%;
  height: 1px;
  background: #ccc;
  transform: scaleY(0.5);
  transform-origin: 0 0;
}

/* 方案 2：媒体查询 */
@media (-webkit-min-device-pixel-ratio: 2) {
  .border-1px::after { transform: scaleY(0.5); }
}
@media (-webkit-min-device-pixel-ratio: 3) {
  .border-1px::after { transform: scaleY(0.33); }
}
```

## 响应式布局

```css
/* 媒体查询 */
@media (max-width: 768px) { /* 平板 */ }
@media (max-width: 480px) { /* 手机 */ }

/* rem + 动态根字号 */
html { font-size: calc(100vw / 7.5); } /* 750px 设计稿 */
.header { height: 0.88rem; font-size: 0.32rem; }

/* vw/vh */
.container { width: 90vw; max-width: 1200px; margin: 0 auto; }

/* clamp() 响应式字号 */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }
```

## Flexbox 核心

```css
/* 主轴对齐 */
justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;

/* 交叉轴对齐 */
align-items: flex-start | flex-end | center | stretch | baseline;

/* 多行对齐 */
align-content: flex-start | flex-end | center | space-between | space-around | stretch;

/* 子项属性 */
flex: 1;           /* 等价于 flex: 1 1 0% */
flex: none;        /* 等价于 flex: 0 0 auto */
flex-grow: 1;      /* 放大比例 */
flex-shrink: 0;    /* 缩小比例 */
flex-basis: 200px; /* 初始尺寸 */
```

**flex: 1 vs flex: auto 区别：**
- `flex: 1` → `flex: 1 1 0%` — 初始尺寸为 0，完全按比例分配
- `flex: auto` → `flex: 1 1 auto` — 初始尺寸为内容大小，剩余空间按比例分配

## CSS 选择器优先级

```
!important > 行内样式 > #id > .class / [attr] / :pseudo-class > element / ::pseudo-element > * > 继承
```

**计算规则：** (行内, id, class, element) — 四元组比较

## CSS 属性继承

**可继承：** font-family、font-size、color、line-height、text-align、visibility、cursor
**不可继承：** display、margin、padding、border、width、height、background、position、overflow

## 重排与重绘

| 操作 | 触发 | 代价 |
|---|---|---|
| **重排（Reflow）** | 几何属性改变（宽高、位置、字体大小） | 高（重新计算布局） |
| **重绘（Repaint）** | 外观改变（颜色、背景、visibility） | 中（不需要重算布局） |

**减少重排：**
1. 批量修改 DOM（用 `documentFragment` 或一次性修改 `className`）
2. 避免读写交替（`offsetHeight` 后立即 `style.width`）
3. 对动画元素用 `position: absolute/fixed` 脱离文档流
4. 用 `transform` 代替 `top/left` 做动画（走合成层）

## CSS 动画三种方式

```css
/* 1. Transition — 状态变化时的过渡 */
.button { transition: background-color 0.3s ease; }
.button:hover { background-color: #007bff; }

/* 2. Animation — 更复杂的动画 */
@keyframes slide {
  from { transform: translateX(-100%); }
  to { transform: translateX(0); }
}
.slider { animation: slide 0.5s ease-out; }

/* 3. requestAnimationFrame — JS 驱动的逐帧动画 */
function animate() {
  element.style.left = `${pos}px`;
  pos += 1;
  requestAnimationFrame(animate);
}
```

## 伪类 vs 伪元素

| 类型 | 语法 | 作用 |
|---|---|---|
| **伪类** | `:hover`、`:focus`、`:first-child`、`:nth-child()` | 选择元素的特定状态 |
| **伪元素** | `::before`、`::after`、`::first-line`、`::selection` | 创建虚拟元素或选中元素的一部分 |

`::` 双冒号是 CSS3 规范，`:` 单冒号是 CSS2 兼容写法。实际项目中 `::before` 和 `:before` 都能用。

## 常见追问

### Q: position: sticky 怎么用？和 fixed 什么区别？

**回答要点：**
- `sticky` 是相对定位和固定定位的混合体 — 在滚动到阈值前是 relative，到达阈值后变成 fixed
- 需要指定 `top`/`bottom` 等阈值
- 不能脱离父容器 — 当父元素滚出视口时，sticky 元素也跟着滚走
- `fixed` 相对于视口定位，完全脱离文档流

### Q: 为什么有时候用 margin 会有间距塌陷？

**回答要点：**
相邻的垂直 margin 会合并（取较大值），这是 CSS 规范的行为。解决方法：
1. 给父元素创建 BFC（`overflow: hidden`）
2. 用 padding 代替 margin
3. 给父元素加 `border` 或 `padding`（哪怕 1px）打断合并
4. 用 Flexbox 布局（Flex 子项之间不存在 margin 塌陷）
