# 面试反馈

## 2026-05-05 面试记录

- 表现：⚠️ 有缺口
- 考察要点：WebSocket 与 HTTP 关系、握手过程、跨域、Server Push 区别
- 回答概要：知道 WebSocket 可以跨域、握手走 HTTP Upgrade；但说"基于 HTTP 协议"不够准确
- 薄弱点：WebSocket 连接建立后不再是 HTTP 协议，是独立的 TCP 连接；握手细节（101 Switching Protocols）不熟；"三次握手四次挥手"是 TCP 的，不是 WebSocket 特有的
- 改进方向：理解"握手阶段走 HTTP，连接建立后是独立 TCP 全双工连接"；用 curl 模拟一次 WebSocket 握手观察 Upgrade 请求和 101 响应

## 2026-05-05 综合面试记录

- 表现：⚠️ 有缺口
- 考察要点：WebSocket vs HTTP 长轮询的本质区别（连接方式、数据传输、资源消耗）
- 回答概要：能说出 WebSocket 全双工、一次连接；能对比资源消耗差异；但不清楚 HTTP 长轮询的具体工作机制
- 薄弱点：不知道长轮询是"客户端发请求 → 服务器 hold 住 → 有数据才返回 → 客户端立即再发"的循环
- 改进方向：记住长轮询本质还是请求-响应模型，只是服务器"故意不及时回复"；对比 WebSocket 每次响应后不需要重新发请求
