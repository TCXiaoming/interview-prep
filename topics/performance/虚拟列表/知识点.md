# 虚拟列表（Virtual List）

## 核心原理

虚拟列表的核心思想：**只渲染可视区域内的元素**，通过占位元素撑起滚动条，让用户感知上认为所有数据都在 DOM 中。

```
┌─────────────────────────────┐
│     外层容器 (固定高度)       │  ← overflow: auto, 监听 scroll
│  ┌───────────────────────┐  │
│  │  占位撑高区            │  │  ← height = totalCount * itemHeight
│  │  ┌─────────────────┐  │  │
│  │  │ 可视区域渲染区    │  │  │  ← 只渲染 visibleCount 个元素
│  │  │ item 5          │  │  │
│  │  │ item 6          │  │  │
│  │  │ item 7          │  │  │
│  │  │ item 8          │  │  │
│  │  │ item 9          │  │  │
│  │  └─────────────────┘  │  │
│  │                       │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

## 一、定高虚拟列表

```js
class VirtualList {
  constructor({ container, itemHeight, totalCount, renderItem }) {
    this.container = container;
    this.itemHeight = itemHeight;
    this.totalCount = totalCount;
    this.renderItem = renderItem;
    this.bufferCount = 3; // 缓冲区：上下多渲染几个，避免快速滚动白屏

    this.visibleCount = Math.ceil(container.clientHeight / itemHeight);

    // 占位元素，撑起滚动条
    this.placeholder = document.createElement('div');
    this.placeholder.style.height = `${totalCount * itemHeight}px`;
    container.appendChild(this.placeholder);

    // 渲染区容器
    this.content = document.createElement('div');
    this.content.style.position = 'absolute';
    this.content.style.width = '100%';
    container.appendChild(this.content);

    container.style.position = 'relative';
    container.style.overflow = 'auto';
    container.addEventListener('scroll', () => this.onScroll());
    this.render();
  }

  onScroll() {
    if (this.ticking) return;
    this.ticking = true;
    requestAnimationFrame(() => {
      this.render();
      this.ticking = false;
    });
  }

  render() {
    const scrollTop = this.container.scrollTop;
    const startIndex = Math.floor(scrollTop / this.itemHeight);
    const renderStart = Math.max(0, startIndex - this.bufferCount);
    const renderEnd = Math.min(
      this.totalCount,
      startIndex + this.visibleCount + this.bufferCount
    );

    // 关键：通过 translateY 定位渲染区
    this.content.style.transform = `translateY(${renderStart * this.itemHeight}px)`;

    this.content.innerHTML = '';
    for (let i = renderStart; i < renderEnd; i++) {
      const item = this.renderItem(i);
      item.style.height = `${this.itemHeight}px`;
      this.content.appendChild(item);
    }
  }
}
```

**关键公式：**
```
scrollTop = 500px, itemHeight = 50px
→ startIndex = floor(500 / 50) = 10
→ renderStart = max(0, 10 - 3) = 7
→ renderEnd = min(total, 10 + 10 + 3) = 23
→ translateY = 7 * 50 = 350px
```

## 二、不定高虚拟列表

核心思路：**预估高度 + 缓存真实高度 + 测量修正**

```js
class DynamicVirtualList {
  // 高度缓存：index → 实际高度
  // 位置缓存：index → { top, bottom, height }

  recalcPositions() {
    let top = 0;
    for (let i = 0; i < this.totalCount; i++) {
      const height = this.heightCache.has(i)
        ? this.heightCache.get(i)
        : this.getItemHeight(i); // 未测量的用预估值
      this.positionCache.push({ top, bottom: top + height, height });
      top += height;
    }
    this.totalHeight = top;
  }

  // 二分查找：给定 scrollTop，找到第一个可见元素
  findStartIndex(scrollTop) {
    let low = 0, high = this.totalCount - 1;
    while (low <= high) {
      const mid = Math.floor((low + high) / 2);
      if (this.positionCache[mid].bottom <= scrollTop) {
        low = mid + 1;
      } else if (this.positionCache[mid].top > scrollTop) {
        high = mid - 1;
      } else {
        return mid;
      }
    }
    return low;
  }

  // 渲染后测量真实高度并更新缓存
  measureItems() {
    const children = this.content.children;
    for (let i = 0; i < children.length; i++) {
      const index = parseInt(children[i].dataset.index);
      const realHeight = children[i].getBoundingClientRect().height;
      if (this.heightCache.get(index) !== realHeight) {
        this.heightCache.set(index, realHeight);
        this.recalcPositions(); // 高度变了需要重算
      }
    }
  }
}
```

## 三、React 实现

```jsx
function VirtualList({ items, itemHeight, height }) {
  const [scrollTop, setScrollTop] = useState(0);
  const totalHeight = items.length * itemHeight;
  const visibleCount = Math.ceil(height / itemHeight);
  const startIndex = Math.floor(scrollTop / itemHeight);
  const endIndex = Math.min(items.length, startIndex + visibleCount + 5);

  const handleScroll = useCallback((e) => {
    setScrollTop(e.currentTarget.scrollTop);
  }, []);

  const visibleItems = useMemo(() => {
    return items.slice(startIndex, endIndex).map((item, i) => (
      <div
        key={startIndex + i}  // key 要用绝对 index
        style={{
          height: itemHeight,
          position: 'absolute',
          top: (startIndex + i) * itemHeight,
        }}
      >
        {item.content}
      </div>
    ));
  }, [items, startIndex, endIndex, itemHeight]);

  return (
    <div
      onScroll={handleScroll}
      style={{ height, overflow: 'auto', position: 'relative' }}
    >
      <div style={{ height: totalHeight }}>{visibleItems}</div>
    </div>
  );
}
```

## 四、常见坑

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 快速滚动白屏 | 渲染跟不上滚动速度 | 增加 buffer 区大小 |
| 图片加载跳高 | 图片异步加载撑高元素 | 固定 `aspect-ratio` 或 `ResizeObserver` |
| 滚动定位不准 | 目标元素还没渲染 | 手动计算 `scrollTop = positionCache[index].top` |
| 内存泄漏 | 频繁创建/销毁 DOM | DOM 池化复用 |

## 常见追问

### Q: 虚拟列表和分页的区别？

**回答要点：**
- **虚拟列表** — 数据全部加载到内存，只渲染可视区域的 DOM，滚动体验连续
- **分页** — 每次只加载一页数据，需要用户点击翻页
- 虚拟列表适合数据量大但单条数据小的场景（聊天记录、还款明细）
- 分页适合需要精确跳转的场景（后台管理表格）

实际项目中可以结合：数据分批从后端加载（无限滚动），前端用虚拟列表渲染已加载的数据。

### Q: 虚拟列表怎么做横向滚动？

**回答要点：**
原理一样，把纵向的 `scrollTop` 换成横向的 `scrollLeft`，`itemHeight` 换成 `itemWidth`，`translateY` 换成 `translateX`。复杂的是横向+纵向双虚拟列表（如 Excel 表格），需要同时计算行和列的可见范围。

### Q: 你项目中虚拟列表是怎么用的？

**参考回答（贷后自助服务平台）：**
还款明细页有 500+ 条数据，如果全部渲染，DOM 节点太多导致滚动卡顿。接入了虚拟列表后，任何时候 DOM 中只有可视区域 + 缓冲区的 15-20 个节点，滚动很流畅。因为每项高度固定（50px），用的是定高方案，实现比较简单。

1. 能手写定高虚拟列表 — 核心就是"占位撑高 + 窗口渲染 + 位置映射"
2. 不定高方案要说清"预估 → 测量 → 修正"的闭环
3. 二分查找加速 startIndex 定位是加分项
