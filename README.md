# 前端面试准备

9 年前端，中高级前端 / 前端组长面试系统化准备仓库。

## 项目结构

```
resume.md              # 简历
projects/              # 项目经历（逐字稿 + 追问清单）
topics/                # 八股文知识点
```

## 知识点分类

涵盖 **18 个分类**、50+ 知识点：

| 分类 | 核心知识点 |
|------|-----------|
| **js-basic** | 闭包、原型链、事件循环、Promise、this 指向、隐式类型转换、并发控制 |
| **react** | Fiber 架构、合成事件、useEffect/useLayoutEffect、key 的作用、useCallback、useMemo |
| **vue** | 响应式原理、ref/reactive、模板编译优化、computed 缓存、状态管理 |
| **css** | 盒模型、flex 布局、position 定位、层叠上下文 |
| **browser** | 渲染流程、重排重绘、合成层、跨域、缓存策略 |
| **network** | HTTP/HTTPS、TCP/WebSocket、HTTP/2 多路复用 |
| **engineering** | Webpack 原理与优化、Vite 原理、Tree Shaking |
| **performance** | 首屏优化、虚拟列表、性能优化体系 |
| **security** | XSS/CSRF、CSP、Token 认证安全 |
| **微前端** | qiankun 沙箱、CSS 隔离、子应用通信、工程兜底 |
| 更多 | Vue vs React、架构设计、项目管理、AI 编程等 |

每个知识点目录包含：
- `知识点.md` — 核心概念 → 常见追问 → 回答要点
- `常见问题.md` — 典型面试题及参考回答
- `面试反馈.md` — 模拟面试记录（薄弱点追踪）

## 面试工作流

### ✍️ 项目逐字稿

使用 `/project-storytelling` 技能，基于简历和项目细节，按 STAR 结构生成口语化项目介绍，支持完整版和简短版，可迭代打磨。

### 🗣️ 模拟面试

使用 `/mock-interview` 技能，由 AI 模拟面试官进行互动提问，覆盖所有知识点分类，面试结束后自动生成复盘反馈并更新薄弱点记录。

### 📝 八股文复习

围绕指定 topic 分类进行交互式讨论，深入理解每个知识点的原理、权衡和实际踩坑经验。

## 内容规范

- **口语化**：逐字稿是说的不是写的，去 AI 味，禁止空洞形容词
- **具体化**：不说"性能优化"，说"首屏加载从 4s 降到 1.2s"
- **有决策**：说清选型原因和取舍
- **有踩坑**：分享实际遇到的坑和解决过程
- **中文撰写**，技术术语保留英文
